Zoom 수업 영상

사용 설명서 · 버전 0.1.0 · Windows 전용

1. 설치하기 (처음 한 번)

  1. 받은 파일 ZoomClassVideo-0.1.0-setup.exe를 두 번 클릭합니다.
  2. "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
    (서명되지 않은 프로그램이라 처음에 한 번 뜨는 정상 안내입니다.)
  3. 설치 위치는 그대로 두고 [설치] → [마침]을 누릅니다.
  4. 바탕화면에 "Zoom 수업 영상" 아이콘이 생깁니다.
설치 없이 쓰려면 ZoomClassVideo-0.1.0-portable.exe를 바로 실행해도 됩니다. (USB에 넣어 다닐 때 편리)

2. 영상 등록하기 (수업 전에)

영상은 최대 20개까지 등록할 수 있고, 프로그램을 껐다 켜도 그대로 남아 있습니다.

  1. YouTube에서 보여 줄 영상을 열고 [공유] → [복사]로 주소를 복사합니다.
    (주소창의 주소를 복사해도 됩니다.)
  2. 프로그램 오른쪽 위 + 영상 등록을 누릅니다.
  3. 칸을 채웁니다.
    칸입력할 내용
    영상 이름 (필수)수업에서 알아보기 쉬운 이름. 예) 구연동화 1, 오늘의 찬양
    YouTube 주소 (필수)복사한 주소를 붙여 넣기 (Ctrl + V)
    시작 초영상 중간부터 보여 줄 때만. 예) 1분 30초부터 → 90. 비우면 처음부터
    종료 초영상 중간에서 끝낼 때만. 예) 4분에서 끝 → 240. 비우면 끝까지
    메모자유롭게. 예) 2주차 수업용
  4. 저장을 누릅니다. 주소가 잘못되었으면 빨간 글씨로 알려 줍니다.

목록을 파일로 저장하고 불러오기

수업별로 영상 목록을 미리 만들어 파일로 저장해 두고, 필요할 때 불러올 수 있습니다.

  • 💾 목록 저장 지금 목록을 파일로 저장합니다. 파일 이름을 직접 정합니다. 예) 2주차 수업
  • 📂 불러오기 저장해 둔 파일을 골라 불러옵니다. 지금 목록은 불러온 목록으로 바뀝니다.
  • 🗑 리셋 등록한 영상을 모두 지웁니다. (확인을 한 번 묻습니다. 파일로 저장해 둔 목록은 지워지지 않습니다)
  • 화면 위쪽 "저장 파일: 2주차 수업"에서 지금 어떤 목록인지 확인할 수 있습니다. 저장 뒤에 목록을 고치면 "(수정됨 · 저장 안 함)"이 붙습니다.
  • 저장한 파일을 카카오톡이나 USB로 다른 선생님께 보내면, 그 PC에서 불러와 같은 목록을 쓸 수 있습니다.

3. 수업 중에 영상 보여 주기

시작 전 준비

  1. 평소처럼 Zoom 회의에 먼저 들어갑니다. (호스트가 아니라면 공유 권한이 있어야 합니다)
  2. 바탕화면의 Zoom 수업 영상을 실행합니다.

영상 보여 주기

  1. 목록에서 보여 줄 영상의 ▶ 공유 재생을 누릅니다.
  2. 화면 아래에 빨간 경고 띠가 떠 있는 동안 마우스와 키보드를 만지지 마세요. 영상이 재생되면 띠가 사라집니다.
    프로그램이 Zoom 공유 창을 열고, ZOOMAUTO PLAYER 창 선택 → 소리 공유와 비디오 공유에 최적화 체크 → [공유]를 자동으로 누릅니다.
  3. 아래 상태 칸에 "Zoom: 영상 창을 소리와 함께 공유 중"이 뜨면 영상이 자동으로 재생됩니다.
  4. 영상이 끝나면 공유가 자동으로 멈추고 카메라 화면으로 돌아갑니다. 강의를 이어 가세요.
공유가 확인되지 않으면 영상을 재생하지 않습니다. 이때는 빨간 안내와 함께 아래 "수동으로 공유하기" 방법이 화면에 나옵니다.

영상 도중 버튼

버튼하는 일
▶ 재생 ❚❚ 일시정지영상을 잠시 멈추거나 다시 재생합니다. (공유는 계속됩니다)
⟲ 처음부터영상을 시작 위치로 되돌려 다시 재생합니다.
■ 공유 중지Zoom 공유만 멈춥니다. 영상 창은 남아 있습니다.
강의로 복귀영상을 중간에 끝낼 때. 공유를 멈추고 영상 창을 닫습니다.

4. 자동 공유가 안 될 때 (수동으로 공유하기)

  1. Zoom 회의 화면 아래의 초록색 [공유] 버튼을 누릅니다.
  2. 창 목록에서 ZOOMAUTO PLAYER를 고릅니다.
  3. 오른쪽 아래 소리 공유에 체크합니다. (빠뜨리면 참가자에게 소리가 안 들립니다)
    바로 아래 비디오 공유에 최적화에도 체크합니다. (영상 끊김이 줄어듭니다)
  4. 파란 [공유] 버튼을 누른 뒤, 이 프로그램에서 ▶ 재생을 누릅니다.
  5. 영상이 끝나면 Zoom 화면 위쪽의 빨간 [공유 중지]를 누릅니다.

자주 나오는 안내와 해결 방법

화면에 나온 안내해결 방법
Zoom 회의 창을 찾을 수 없습니다Zoom 회의에 먼저 들어간 뒤 다시 누릅니다.
공유 목록에서 영상 창을 찾지 못했습니다영상 창(ZOOMAUTO PLAYER)이 최소화되어 있으면 펼친 뒤 다시 누릅니다.
"소리 공유" / [공유] 버튼을 찾지 못했습니다Zoom 공유 창이 다른 창에 가려졌거나 Zoom이 업데이트된 경우입니다. 수동으로 공유하세요.
영상 주인이 다른 곳에서 재생하는 것을 막아 두었습니다이 영상은 프로그램에서 재생할 수 없습니다. 다른 영상을 쓰거나 YouTube에서 직접 공유하세요.
YouTube에 연결할 수 없습니다인터넷 연결을 확인합니다.

5. 꼭 알아 둘 점

  • 자동 공유가 진행되는 약 5초 동안은 마우스를 움직이지 마세요. 엉뚱한 곳이 눌릴 수 있습니다.
  • Zoom 화면 언어는 한국어 또는 영어여야 합니다.
  • 공유 중에 Zoom에서 직접 공유를 멈추면 몇 초 안에 영상이 자동으로 일시정지됩니다. 영상 창을 직접 닫으면 공유도 함께 멈춥니다.
  • 공유 중에 다른 영상의 ▶ 공유 재생을 누르면, 앞의 공유를 멈추고 새 영상으로 넘어갑니다.
  • Zoom이 업데이트된 뒤에는 수업 전에 한 번 미리 시험해 보세요.
  • 영상 목록은 PC마다 따로 저장됩니다. 다른 PC에서는 저장한 목록 파일을 불러오면 됩니다.
  • 영상을 내려받지 않고 YouTube에서 바로 재생하므로 인터넷 연결이 필요합니다.
