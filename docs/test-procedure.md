# Zoom 공유 자동화 테스트 절차 (2단계 PoC)

준비: Zoom 회의 입장(호스트), 참가자 역할 폰 1대 입장, 이 앱 실행 (`npm start`)

## 한 번의 테스트
1. 앱에 YouTube 주소를 넣고 **① 영상 열기** → `ZOOMAUTO PLAYER` 창이 뜨고 "준비됨" 표시
2. **② Zoom 공유하며 재생** → 마우스를 움직이지 말고 기다림
3. 확인 A (공유 시작): 폰 화면에 영상 창이 보이는가
4. 확인 B (소리 전달): 폰에서 영상 소리가 들리는가
5. 영상이 끝날 때까지 둠 (빨리 하려면 끝부분으로 넘겨도 됨)
6. 확인 C (복귀): 공유가 멈추고 폰 화면이 카메라 화면으로 돌아왔는가
7. 앱의 Zoom 상태 상자 내용과 A/B/C 결과를 아래 표에 기록

## 추가 상황
| 상황 | 방법 |
|---|---|
| Zoom 창 최소화 | 회의 창을 최소화한 뒤 ② |
| 다른 창에 가려짐 | 브라우저 등을 Zoom 위로 올린 뒤 ② |
| 소리 공유가 이미 체크됨 | 직전 테스트 바로 뒤 ② (체크가 해제되지 않아야 함) |
| 화면 배율 125%/150% | Windows 설정 > 디스플레이 > 배율 변경 후 ② |
| 모니터 2대 | Zoom 회의 창을 보조 모니터로 옮긴 뒤 ② |
| 수동 중지 | 재생 중 **■ 공유 중지** → 공유가 멈추는가 |
| 강의로 복귀 | 재생 중 **강의로 복귀** → 공유 중지 + 영상 창 닫힘 |
